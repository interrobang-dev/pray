# 웹 화면 틀 (App·목록·패널·테마·모달)

3열 화면(App.tsx: 목록·패널·상태 표시줄·폰 한 열·사무실 숨기기), 응답 타입과 공통 문구 함수, 테마·스크롤바·로고, 추가 모달과 목록 메뉴, 그룹 할 일 화면, 역할 칩, 모델·effort 변경 창을 다룬다.

원래 루트 `CLAUDE.md` 한 파일이던 내용을 옮긴 것이다. 본문의 "위·아래 …"·"핵심 개념 …" 은 그때의 말이라 가리키는 항목이 다른 파일에 있을 수 있다. 어디서나 지킬 규칙·근무·휴식·퇴근·표시 상태·실행 방법은 루트 `CLAUDE.md`, 다른 영역은 루트의 문서 지도를 본다. 이 영역을 고치면 이 파일의 그 줄을 고쳐 쓴다.

다른 파일에 있는 항목:
- 사무실 캔버스(그룹 TODO 버튼 그림 포함) → office.md
- 대화 탭 → chat.md
- 사용량 창·계정 → accounts.md
- Flow 패널 → flow.md
- 모델·effort 바꾸기 서버 규칙 → server-api.md
- 세션 이름·역할 저장 규칙 → server-api.md

## 구조

- `web/src/main.tsx` — `/api/auth/me` 로 인증 상태를 보고 `Login` 또는 `App` 을 띄운다
- `web/src/App.tsx` — 3열: 좌측 목록(그룹 라벨 → 팀 카드 → 세션 줄, 맨 아래 Focus Zone(로비), 그 아래 Off Duty(퇴근 세션, 기본 접힘·라벨 클릭으로 펼침. 사무실 퇴근 거리의 "+N" 을 누르면(`onShowOffDutyList`) 펼치고 그 구역으로 목록만 스크롤한다 — `scrollIntoView` 는 overflow hidden 인 조상까지 움직여서 목록 `scrollTo`. 줄 제목은 "팀명 · 이름"(팀 없으면 이름과 폴더)이고 시각 자리에 퇴근 이유 · 시각 "Left · just now"·"Ended · 3h ago"·"Released by lead · 10m ago"·"Exited with error (code 1) · 2d ago"(오류는 빨강. `types.ts` 의 `offDutyLabel` — 퇴근 막대·사무실 퇴근 거리 카드도 같은 함수). 팀 카드·로비에는 근무·휴식 세션. 휴식은 "Break" 배지). 세션 줄은 아바타·제목(앞에 회색 역할 칩 `PositionChip`, 퇴근 줄은 "팀명 · 칩 이름". 역할이 없으면 칩 없이)·모델·시각이고 **팀 안 세션은 폴더를 숨긴다**(팀 = 폴더). 모델 글자("Opus 5.5 · xhigh", 회색)는 grid 의 `minmax(0, 1fr)` 칸이라 남는 폭만 쓰고 제목이 길면 말줄임되다 사라진다. **세션 줄 ⋯ 메뉴 (데스크톱·마우스 기기만)**: 마우스를 올리면(또는 메뉴가 열려 있는 동안) 오른쪽 끝 시각(퇴근은 "이유 · 시각") 자리에 ⋯ 가 나타나고 시각은 숨는다 — 둘이 `.session-tail` 의 같은 grid 칸에 겹쳐 있어 줄 폭·제목 말줄임이 안 바뀐다. 폭 768px 이하·`(hover: none)` 에서는 ⋯ 를 렌더하지 않는다(줄을 누르면 패널이 열린다). ⋯ 를 눌러도 세션 선택은 안 일어난다(래퍼가 클릭 전파를 막는다). 메뉴 항목은 `sessionMenu.ts` 의 `sessionMenuEntries` 가 고른다(`sessionMenu.test.ts`): 근무 중인 웹 = Rename…·Model & effort…·─·End session, 휴식 웹·외부 = Rename…, 퇴근 웹(`attendance` 가 'off' 일 때만. 옛 서버 응답은 이름만) = Rename…·Clock in·─·Delete record. `returningSessions` 에 넣어 근무로 바뀔 때까지 메뉴 항목이 비활성 "Clocking in…". 다시 띄우는 중이면 Model & effort… 비활성 "Restarting…"). 퇴근 줄(`.session.dead`)은 줄 전체가 아니라 메뉴를 뺀 자식만 흐리게 한다 — 줄에 opacity 를 주면 메뉴까지 흐려 비활성처럼 보인다. 팀 카드 안은 팀 직속 세션 → 파트 소제목 → 파트 세션 (각 묶음 안은 서버 순서 그대로 = 생성순, 상태로 다시 정렬하지 않는다) 순. 파트 소제목은 이름·세션 수·hover 버튼이고, worktree 파트만 이름 왼쪽에 회색 브랜치 아이콘(`WorktreeIcon`, 인라인 SVG `currentColor`, 줄지 않음)을 둔다 — 브랜치 이름은 글자로 쓰지 않고 그 아이콘의 `title`·`aria-label` "worktree · <브랜치>"(`role="img"`)로만 보인다 (소제목의 나머지 자리 title 은 폴더 경로). 팀 폴더 파트는 아이콘 자리 없이 이름만. 글자 배지는 승인 대기·휴식만. **상태는 점이 아니라 아바타 테두리**다(`.session .avatar` 의 `::after` 안쪽 2px 테두리라 크기·줄 높이가 그대로): 작업 중 파랑(`--blue-dot`, 테두리만 `dot-breathe` 숨쉬기 — 그림은 안 흐려진다. reduced-motion 이면 멈춤)·백그라운드 대기(waiting) 파랑 점선(움직임 없음)·승인 대기 빨강·내 차례(my-turn, 사람에게 물었다) 주황 `--yellow`·끝남(done, 묻지 팀장·파트장이면 앞에 "Lead · "·"Part lead · "(팀장·파트장 구분은 테두리가 아니라 이 글자뿐)), 가운데 사무실, 우측 패널 (세션 선택 시. 툴바 세 번째 Flow 버튼을 누르면 같은 자리에 플로우 알림 패널(`FlowPanel.tsx`)이 열리고 `isFlowOpen`·`selectedId` 는 서로를 닫는다 — 세션을 **근무 중인 웹 세션의 칩은 버튼**이라 누르면 모델·effort 변경 창(`ModelSettingModal`)이 뜬다(목록 세션 줄 ⋯ 메뉴도 같은 창을 연다. 창은 `modelModalSessionId` 로 세션 목록에서 대상을 찾아 그려 패널 선택과 무관하다) — 외부·휴식·퇴근 세션은 글자만. 저장된 `modelSetting` 이 지금 응답의 Firefox 는 확인하지 않았다. 폰 헤더 grid 는 6칸(`auto minmax(0, max-content) 1fr auto auto auto`)이고 검색 버튼이 1행 5칸, 종료 버튼이 1행 6칸으로 칸을 정해 둔다 — 검색 버튼은 대화 탭에만 있어 자동 배치에 맡기면 둘째 줄로 밀린다. 대화 탭 / 터미널 탭 — 글자 없는 아이콘 패널이 닫힌다). `attendance` 가 없는 옛 서버 응답은 `attendanceOf`(types.ts)가 isAlive 로 근무/퇴근을 정하고, 퇴근 웹 세션은 버튼 없이 "Off duty · Record is view only". 다른 세션을 고르거나 세션을 만들면 대화 탭으로 열고, 같은 세션을 다시 누르면 보던 탭 그대로. 선택과 탭은 팀 섬으로 이동시킨다 (사무실 숨김·폰 폭이면 넘기지 않는다). **점프·돌아가기**: 팀장 대화의 지시·보고 한 줄을 누르면(Chat `onOpenRelay`) `openJump` 가 그 팀원 세션을 대화 탭으로 열고 `jump`(세션 ID·찾을 곳·번호)를 Chat 에 넘기며(Chat 이 처리하면 `onJumpHandled` 로 비운다), - **그룹 할 일 (화면).** `Group.todos` 를 쓴다 (필드가 없는 옛 응답은 `todosOf` 가 []). 남은 = 미완료 수. 목록 그룹 라벨의 TODO 버튼과 사무실 그룹 이름표 옆 TODO 버튼이 App 의 `todoGroupId` 를 정해 같은 `GroupTodosModal` 을 연다 (폰·사무실 숨김에서는 목록 버튼만). 모달은 props 의 그 그룹 todos 를 그대로 그려 열린 동안 사무실 SSE 를 따라가고, 그룹이 사라지면 그리지 않아 닫힌다. 모달(문구 영어): 제목 "TODO · <그룹 이름>" + 닫기 ×(`hasCloseButton`), Esc·바깥 클릭으로도 닫힌다. 맨 위 입력칸 "Add a task": Enter 로 추가(한글 조합 중 Enter 무시, 빈 글은 보내지 않음. 길이는 입력칸에서 자르지 않고 서버가 본다 — `maxLength` 를 두면 붙여 넣은 긴 글 끝이 알림 없이 잘려 저장된다. 여러 줄을 붙여 넣으면 브라우저가 줄바꿈을 공백으로 바꿔 넣는다), 추가 뒤 비우고 포커스 유지(기다리는 사이 더 친 글은 남긴다), 열 때 포커스는 마우스 기기만(터치는 가상 키보드가 목록을 가려서. `(hover: none)`). 할 일 줄 = 체크박스 · 글 · 삭제 × · 끌기 손잡이 ⠿ (×·⠿ 는 줄에 마우스를 올리거나 포커스가 있을 때만, 터치 기기는 늘 40px). 글을 누르면 그 자리에서 고친다: Enter 저장, Esc 취소(이벤트를 멈춰 모달은 안 닫힌다), 포커스가 빠지면 저장, 빈 글이면 저장하지 않고 되돌리고, 그대로면 보내지 않는다. 그 아래 완료 "Done (N)"(있을 때만): 최근 완료부터, 줄 긋고 흐리게, 글 고치기·끌기 없음, × 있음, 체크를 풀면 할 일 맨 끝으로 간다. 할 일이 없으면 "No tasks". **추가·체크·글·삭제는 응답을 기다려 받은 항목을 `applyTodo`·`removeTodo` 로 App 의 office 에 먼저 넣는다** — 서버 순서 규칙과 같은 자리라 SSE 가 먼저 와 있어도 결과가 같다. **순서 바꾸기만 화면을 먼저 바꾸고**(`reorderOpen`) `PUT …/todos/order` `{ ids }`(미완료 전부)를 보내 실패하면 원래 순서로 되돌린다. 끌기는 App 목록 끌어 놓기와 같은 방식(pointer 이벤트, 5px 넘게 움직여야 끌기, 줄 세로 가운데로 놓일 자리, 초록 선, 모달 목록 위·아래 끝 자동 스크롤). 실패는 입력칸 아래 빨간 한 줄(서버 `message`, 없으면 HTTP 코드, 서버에 닿지 못하면 "Network error". 순서 실패는 "Couldn't change the order: …")이고 다음 요청 때 지운다
- **좌측 목록 순서 = `hq.json` 의 `groups`·`teams` 배열 순서** (처음엔 만든 순, 목록 끌어 놓기로 바꾼다). 사무실은 좌표로 그려 순서와 무관하다 — 목록 순서를 바꿔도 사무실은 그대로, 사무실에서 옮겨도 목록 순서는 그대로다. 팀 순서는 그룹별이라 `teams` 배열에서 그 그룹 팀들이 차지한 자리끼리만 바꾼다 (같은 규칙 `reorderSlots` 가 `hq.ts` 와 `App.tsx` 에 따로 있다. 화면 쪽은 바로 반영·실패 때 되돌리기용). 사무실에서 섬을 다른 그룹으로 옮기면 그 팀은 배열 자리 그대로라 새 그룹 안에서의 순서는 배열 위치로 정해진다
