# 웹 화면 틀 (App·목록·패널·테마·모달)

3열 화면(App.tsx: 목록·패널·상태 표시줄·폰 한 열·사무실 숨기기), 응답 타입과 공통 문구 함수, 테마·스크롤바·로고, 추가 모달과 목록 메뉴, 팀 할 일 화면, 역할 칩, 모델·effort 변경 창을 다룬다.

원래 루트 `CLAUDE.md` 한 파일이던 내용을 옮긴 것이다. 본문의 "위·아래 …"·"핵심 개념 …" 은 그때의 말이라 가리키는 항목이 다른 파일에 있을 수 있다. 어디서나 지킬 규칙·근무·휴식·퇴근·표시 상태·실행 방법은 루트 `CLAUDE.md`, 다른 영역은 루트의 문서 지도를 본다. 이 영역을 고치면 이 파일의 그 줄을 고쳐 쓴다.

다른 파일에 있는 항목:
- 사무실 캔버스(팀 TODO 버튼 그림 포함) → office.md
- 대화 탭 → chat.md
- 사용량 창·계정 → accounts.md
- Flow 패널 → flow.md
- 모델·effort 바꾸기 서버 규칙 → server-api.md
- 세션 이름·역할 저장 규칙 → server-api.md

- 팀 할 일 화면은 단위 테스트와 Vite dev + CDP 가짜 `/api`(가짜 상태로 응답하고 SSE 를 다시 붙여 바뀐 office 를 보낸다. 실제 서버에는 GET 만)로만 확인했다 (headless 1600×900 라이트·다크, 폰 390×844 라이트·다크: 목록 버튼 남은 0·1·3·12와 hover, 그룹이 지워진 팀의 버튼, 320px 목록 폭에서 이름 말줄임·vcs 칩 유지, 모달 제목 "TODO · <팀 이름>"·추가·체크·삭제·끌기(초록 선·PUT `/api/team/:id/todos/order`)·팀이 지워지면 닫힘, 사무실 1배·2배·0.75배·0.5배의 명판 옆 버튼과 배지, 버튼 위에서 누르고 끌기(요청·모달 없음)·클릭·더블클릭으로 모달(이름 변경 입력 창 없음)). 서버 API 와의 연동(실제 `/api/team/:teamId/todos`), 실행 중인 서버(트레이)로 띄운 화면, 한글 조합 중 Enter, 할 일이 모달 높이를 넘을 때 끌며 자동 스크롤, 실제 폰·태블릿, 트레이 앱 창, 빈 글·고치기·체크 실패 줄은 이번 이동 뒤 다시 보지 못했다 (모달 코드는 그대로)
