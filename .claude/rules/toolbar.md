# 목록 툴바·사이드바 탭 (New Group·Reminders·Lead models · Sessions·Needs you·All TODOs) · 글로벌 검색 (Ctrl+K)

좌측 목록 위 툴바 줄들과 탭 줄, 그것이 여는 사이드바 보기·창, 헤더 돋보기·Ctrl+K 로 여는 글로벌 검색 창을 다룬다. 세션 목록·New Group 창은 web-app.md, 할 일 모달·규칙("팀 할 일 (화면)")은 web-app.md, 모델·effort 바꾸기 서버 규칙은 server-api.md 다. 이 영역을 고치면 이 파일의 그 줄을 고쳐 쓴다.

## 구조

- **툴바·탭 꼴** (App.tsx, style.css `.toolbar`·`.toolbar-row`·`.side-tabs`·`.side-tab`): 헤더 아래 **줄마다 하나** — "New Group"(그룹 만들기 창) · "Reminders"(알림 창 → reminders.md) · "Lead models"(아래 창). 셋 다 아이콘 + 글자 전체 폭 `.toolbar-row` 이고 셋 다 투명 줄(hover 때만 `--surface-2`. 하나만 채우면 눌린 항목처럼 읽혀서), 줄 안 배지는 오른쪽 끝. 그 아래 **탭 줄** `role="tablist"`: Sessions · Needs you · All TODOs 세 칸 같은 폭(`--surface-2` 알약 홈 안 투명 칸, 고른 탭 `--accent-soft` 면 + `--accent-text` 굵게 — 강조색을 채우지 않는 것은 탭 안 배지 색(빨강·주의색)이 살게. `aria-selected`). 탭이 App 의 `sidebarView`(sessions·needs-you·todos)를 정하고 툴바 아래 목록 자리 전체를 그 보기가 쓴다 (세션 목록 `<ul>` 은 지우지 않고 `hidden` 으로 숨겨 돌아오면 스크롤·접기가 그대로). 보기 머리줄·← 는 없다 (탭이 돌아가기를 맡는다). 고른 탭을 다시 눌러도 그대로다. 바깥 클릭·Esc 로 바뀌지 않는다. 폰은 줄·탭 40px(탭 글자 13px). 툴바가 4줄이라 세션 목록이 예전(1줄)보다 약 110px 짧다 (받아들인 값)
- `web/src/NeedsYouButton.tsx`·`needsYou.ts` — **사이드바 탭 "Needs you" 모아 보기** (근무 세션이 많아 아바타 테두리를 훑지 않고 답을 기다리는 세션을 찾으려고): 탭 `NeedsYouTab`(글자 "Needs you" + 개수 배지 — 승인 대기가 있으면 빨강 `--red-fill`·`--on-red`, 아니면 `--surface-3`. 0 이면 배지 없이 눌린다) → 보기 `NeedsYouView`. 줄을 눌러도 보기는 남아 차례로 처리한다. 다 빠지면 "Nothing needs you". **넣는 세션**(`isNeedsYou`): 근무 중이고 승인 대기(팀원 포함)·내 차례·끝남. 내 차례·끝남은 팀원(`role === 'member'`)을 뺀다 — 팀원의 끝은 팀장이 team_wait 로 받는다 (트레이 알림 `desktop/src/notify.ts` 의 `noticeKind` 와 같은 규칙. desktop 은 CommonJS 라 따로 두니 같이 고친다). **끝남은 마지막 대화(`turnEndedAt` → `lastAt`)에서 24시간(`DONE_MAX_AGE_MS` = `dotState.ts` 의 `LOUNGE_DOZE_AFTER_MS`)이 지나면 뺀다** — done 은 다음 지시까지 그대로라 쌓이기만 하고, 사무실이 같은 시계·같은 기준으로 라운지에서 졸게 하므로 맞췄다 (밤새 끝난 일은 다음 날 아침까지 남는다. 주말을 넘긴 금요일 done 은 빠진다). 시각을 모르면 넣고, 내 차례·승인 대기는 오래돼도 넣는다. 읽었는지는 보지 않는다(읽은 done 도 24시간 남는다). **순서**(`needsYouSessions`): 승인 대기 → 내 차례 → 끝남, 묶음 안은 최근 먼저(`home.ts` 의 `lastActivityOf`, 모르면 뒤, 같으면 생성순). 줄 = 목록과 같은 아바타(`renderAvatar`, 상태 테두리 CSS 는 `:is(.session, .home-row, .needs-you-row) .avatar`) · 역할 칩 + 이름 · 오른쪽 `formatAgo` / 둘째 줄 "팀 · 상태"(팀 없으면 Focus Zone, `statusLabel`). 폰 줄 44px. 누르면 보기는 그대로 두고 `selectSession`(목록 세션 줄과 같다 — 사무실 포커스 포함). `needsYou.test.ts`
- `web/src/AllTodosButton.tsx` — **사이드바 탭 "All TODOs" 모아 보기** (팀마다 TODO 모달을 열지 않고 남은 할 일을 다 보려고): 탭 `AllTodosTab`(글자 "All TODOs" + 내 책상·모든 팀 남은 합계 배지 — `totalRemaining`, `.needs-you-count`. 미완료에 Critical 이 있으면 빨강 바탕, High 만 있으면 주의색 글자·테두리 — `totalUrgentPriority`·`data-priority`, Medium·Low 는 그대로. 0 이면 배지 없음) → 보기 `AllTodosView`(목록 자리를 다 쓰고 안에서 스크롤). **맨 위는 늘 "My desk"(팀과 무관한 내 할 일 `Office.todos`)**: 머리줄 "My desk" + 남은 수(0 이어도), 그 아래 입력칸 "Add a task"(`.all-todos-add`, TODO 모달 입력칸과 같은 규칙: Enter 로 `POST /api/todos`, 한글 조합 중 Enter 무시, 빈 글은 안 보냄, `maxLength` 없음, 기다리는 사이 더 친 글은 남김. 열 때 포커스는 주지 않는다), 미완료 줄. 미완료가 하나도 없어도 이 묶음과 입력칸은 보인다 (그래서 "No tasks" 줄은 없다). 그 아래 팀 묶음(`openTodoGroups`): 목록 순서(`teamsInListOrder` — 그룹 hq 배열 순 → 그 그룹 팀의 배열 순, 그룹이 지워진 팀은 맨 뒤)대로 미완료가 있는 팀만, 머리줄 = 팀 이름 + 남은 개수, 그 아래 미완료를 서버 순서대로 (글은 두 줄까지, 전문은 title. 우선순위가 있으면 글 앞에 칩 `PriorityChip` 만 — 바꾸기는 모달). 체크 = 그 범위의 `PATCH …/todos/:todoId` `{ isDone: true }` 를 `requestTodo`(TeamTodosModal.tsx 에서 export)로 보내고 기다리는 동안 그 체크박스는 체크·비활성, 응답 항목을 `applyTodo` 로 App 의 office 에 넣으면 줄이 빠진다. 실패는 제목 아래 빨간 한 줄(다음 요청·다시 열 때 지운다). **묶음 머리줄(My desk·팀 이름)을 누르면 그 범위의 `TeamTodosModal` 을 연다** (`onOpenTodos` → App 의 `todoScope`. 보기는 그대로). 글 고치기·지우기·끌어 놓기·완료 목록은 이 창에 없고(모달이 한다), 추가는 My desk 만 이 창에서 된다. 폰: 머리줄·할 일 줄·My desk 입력칸 44px(입력칸 글자 16px — 데스크톱 13px 규칙이 폰 `input` 16px 를 이겨서 다시 준다), 체크박스 22px

## 글로벌 검색 (Ctrl+K)

화면이 이미 가진 데이터(세션 목록 SSE·office)만 찾는다 — 서버 API 는 없다. 대화 내용·파일은 찾지 않는다 (대화 안 검색 Ctrl+F → chat.md, 작업 폴더 Search → workspace.md).

- **버튼**: 헤더 `headerButtons` 의 Appearance 와 Show/Hide office 사이 돋보기(`GlobalSearchIcon` 14px, `className="icon"`, title "Search (Ctrl+K)", aria-label "Search"). headerButtons 라 트레이 창 띠 `.titlebar-actions` 에도 같이 들어가고(→ theme.md "트레이 창 제목 띠") 폰 헤더에도 보인다 (폰은 톱니·돋보기 둘)
- **키** (App.tsx window keydown, `isGlobalSearchShortcut`): Ctrl+K(맥 Meta+K), Shift·Alt 없이. 한글 자판은 `key` 가 'ㅏ' 라 `code === 'KeyK'` 로도 본다. 가로채면 `preventDefault`(Chrome 의 주소창 검색 키도 막힌다) 하고 열려 있으면 닫는다. **가로채지 않는 때**: ① 포커스(event.target)가 터미널 탭 xterm(`.xterm`) 안 — Ctrl+K 는 Claude Code 입력칸의 "커서부터 줄 끝 지우기" 키라 터미널 사용자가 잃으면 안 된다 ② 검색 창이 아닌 `.modal-overlay`(Modal·Dialog) 가 떠 있음. 대화 입력칸 등 다른 입력칸에서는 가로챈다
- **창** (`GlobalSearch.tsx`): 오버레이는 `.modal-overlay.search-overlay`(띠 아래부터 덮기 규칙 그대로, 위로 붙여 `padding-top: 15vh`), 면 `.search-panel` = 폭 `min(640px, 100vw - 32px)`·`--pop-bg`·`--shadow-pop`·`--radius-lg`, 높이가 넘치면 결과 목록 `.search-list` 만 스크롤. 맨 위 입력칸(placeholder "Search sessions, teams, TODOs, commands", 칸 면·링 없이 글자만)은 열 때 effect 로 포커스 — `autoFocus` 가 아닌 것은 StrictMode 두 번 마운트의 cleanup(포커스 돌리기)이 빼앗은 포커스를 다시 가져오려고. 그 아래 묶음 머리(회색 11px) + 줄. ↑↓ 로 고르고 끝에서 돌며 비활성 명령은 건너뛴다(`moveSelection`), 마우스를 움직이면 그 줄을 고르고(onMouseMove — 목록이 스크롤돼도 고른 줄이 안 튄다), Enter·클릭으로 열고 닫는다. 줄 mousedown 은 `preventDefault` 라 입력칸 포커스가 남는다. 고른 줄 = `--accent-soft`, 목록만 스크롤해 보이게(묶음 첫 줄이면 머리까지, `scrollIntoView` 안 씀). 고른 줄은 키로 기억해 세션 목록 SSE 로 줄이 바뀌어도 남는다(없어지면 첫 줄). 한글 조합 중 Enter·↑↓ 무시. 결과 없음 "No results". Esc 는 window 캡처 keydown 에서 `stopPropagation` 해 밑의 메뉴·사용량 창·대화 Esc 중지가 반응하지 않는다. 바깥(오버레이) mousedown 으로 닫는다. 면은 `role="dialog"` `aria-modal="true"`(대화 Esc 중지가 보는 표시), 입력칸 combobox + 목록 listbox·option. **닫으면 열 때 포커스 요소로 돌린다** — 줄을 고르면 동작을 부르기 **전에** 돌려, 그 동작이 여는 창(TODO 입력칸 등)이나 대화 입력칸의 포커스를 빼앗지 않는다.
