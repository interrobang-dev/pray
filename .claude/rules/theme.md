# 화면 테마·로고·스크롤바

화면 테마(모드·팔레트·강조색·글자 크기)와 설정 창 Appearance 의 App 탭, 첫 화면 번쩍임 방지, 대비 규칙, 스크롤바, 로고 마크·글자 로고, 대화 모양 Colors 줄을 다룬다.

`web-app.md` 가 4만 자를 넘어 나눈 것이다. 본문의 "위·아래 …" 는 그때의 말이라 가리키는 항목이 `web-app.md` 에 있을 수 있다. 이 영역을 고치면 이 파일의 그 줄을 고쳐 쓴다.

다른 파일에 있는 항목:
- 대화 모양(설정 창 Chat 탭·`ChatStyleTab.tsx`·`.chat-scope`) → chat.md
- 트레이·창·exe 아이콘을 만드는 코드(`desktop/src/icon.ts`)·크기 규칙 → host.md
- 3열 화면·상태 표시줄·모달 → web-app.md

## 구조

- `web/src/theme.ts` — 화면 테마(모드 라이트·다크·시스템)와 스타일 설정(팔레트·강조색·글자 크기)의 저장·`<html>` 에 걸기·OS 설정 따라가기, 헤더 버튼·설정 창이 같은 값을 보는 구독(`subscribeTheme`, `useSyncExternalStore`). main.tsx 가 불러와 로그인 화면에도 적용된다 (아래 핵심 개념)
- `web/src/appearance.ts` — 스타일 설정의 순수 로직 (`appearance.test.ts`): 저장 값 해석 `parseAppearance`·`parseThemeChoice`·`resolveMode`, 색 계산(`contrast` WCAG 명암비·`mix`·`ensureContrast` HSL 밝기만 움직여 대비 맞추기), 팔레트 핵심 색 → 변수 전부 `expandPalette`, 강조색 파생 `accentVars`, `<html>` 에 덮을 변수 `overrideVars`·걸 것 전부 `documentState`·인라인 스크립트용 미리 계산 `appearanceBoot`, 대화 모양(`ChatStyle`(색 줄 켜기/끄기 넷 포함)·`CHAT_OPTIONS`·`chatAttributes`·`chatColorVars`·`chatColorWarnings`·`isWorkOpen` → chat.md)
- `web/src/palettes.ts` — `DEFAULT_VARS`(style.css 맨 위 변수 그대로)·팔레트 핵심 색 `PALETTES`(`PaletteCore.markdown` = 제목·인라인 코드·숫자·경로 기본색 포함)·강조색 프리셋 `ACCENT_PRESETS`
- `web/src/AppearanceModal.tsx` — 설정 창 "Appearance" 의 틀(탭 App · Chat)과 App 탭 (아래 핵심 개념). Chat 탭은 `ChatStyleTab.tsx` (→ chat.md)

Google Fonts 가 내려 준 파일 그대로, OFL.txt 같이), `@font-face` 는 `web/src/fonts.css`(main.tsx 가 style.css 앞에서 import, `font-display: swap`, `unicode-range` 는 Google 값 그대로). `index.html` 은 첫 화면 제목용 정체 latin 만 `<link rel=preload crossorigin>`. 굵기·이탤릭을 더 쓰면 woff2 를 받아 fonts.css 에 규칙을 더한다. 파일을 못 받으면 Georgia. 사무실 캔버스(Pixi)는 `system-ui` 라 이 글꼴과 무관), 나머지는 시스템 폰트
- **스크롤바는 `style.css` 위쪽 공통 규칙 하나**(`@media (hover: hover)` 블록: 8px·투명 트랙·둥근 반투명 손잡이 `--scrollbar-thumb`·올리면 진해짐)로 모든 스크롤 영역에 걸린다 — 요소마다 따로 주지 않는다. Chromium(트레이 앱 Electron 포함)·Safari 는 `::-webkit-scrollbar` 로 그리고, 표준 `scrollbar-width`·`scrollbar-color` 는 `@supports not selector(::-webkit-scrollbar)`(Firefox)에만 준다 — **요소에 표준 속성을 걸면 Chromium 이 그 요소의 `::-webkit-scrollbar` 를 무시해** 모양·hover 가 사라진다. 터치 기기(폰)는 OS 오버레이 스크롤바 그대로. 터미널 탭은 늘 어두워 `.terminal` 에서 손잡이 변수를 다크 값으로 덮는다 (xterm FitAddon 은 열 때 스크롤바 폭을 재므로 열 수는 저절로 맞는다)
- **대화 모양 Colors (설정 창 Chat 탭)**: 줄 = Numbers·Paths·Headings·Inline code (링크·인용은 줄이 없고 고정 모양: 링크 = 팔레트 `--link` + 밑줄, 인용 = 팔레트 `--muted` 글자 + `--line` 세로줄. 미리보기에는 남아 있다), 줄마다 [스위치] 이름 [색 칩] [입력] [Clear](폰은 스위치·이름 한 줄, 아래 줄에 색 칸). 스위치는 `<button role="switch" aria-checked>`(Space/Enter, 폭 32×18, 폰 44×26)이고 켜면 강조색·끄면 회색(`--accent`·`--line`·`--muted`·`--on-accent` 만 쓴다). 저장은 `ChatStyle` 의 `numbers`·`paths`·`codeColor`·`headingColor`('on'|'off', 기본 On)와 `colors.*`(code·heading·number·path) 이고 `<html data-chat-numbers|paths|code-color|heading-color="off">` 는 Off 일 때만 걸린다(첫 화면 인라인 스크립트·`documentState` 는 같은 규칙). 예전 저장값의 `linkColor`·`quoteColor`·`colors.link`·`colors.quote` 는 `parseAppearance` 가 알려진 키만 읽어 버린다(에러 없음, 나머지 유지) — `--chat-link`·`--chat-quote`·`data-chat-link-color`·`data-chat-quote-color` 는 더는 걸리지 않는다. **끄면**: Numbers·Paths = 강조 색 없음, Headings·Inline code = 본문색(코드 배경 칩은 유지) — style.css 가 `inherit` 로 처리해 글을 다시 파싱하지 않는다. 끈 줄은 칩·입력·Clear 가 흐려지고 잠기되 골라 둔 `colors` 값은 남아 다시 켜면 그 색이다. 대비 경고(`chatColorWarnings(colors, palette, chat)`)는 켜진 네 줄만. 세그먼트 목록은 `CHAT_SEGMENT_KEYS`(스위치 키 제외). [Reset chat style] = 모두 On·색 비움. 값·CSS 전문은 chat.md "대화 모양".
