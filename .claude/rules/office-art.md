# 도트 스프라이트·인물 그림

목록 아바타·도트 인물 고르기·색 바꾸기, 스프라이트 파이프라인(`tools/sprites/`)과 그 결과 아틀라스(`web/public/office/`)를 다룬다.

원래 루트 `CLAUDE.md` 한 파일이던 내용을 옮긴 것이다. 본문의 "위·아래 …"·"핵심 개념 …" 은 그때의 말이라 가리키는 항목이 다른 파일에 있을 수 있다. 어디서나 지킬 규칙·근무·휴식·퇴근·표시 상태·실행 방법은 루트 `CLAUDE.md`, 다른 영역은 루트의 문서 지도를 본다. 이 영역을 고치면 이 파일의 그 줄을 고쳐 쓴다.

다른 파일에 있는 항목:
- "퇴근 거리" → office.md
- 캔버스에서 인물을 그리는 쪽(Office.tsx) → office.md

## 구조

- **목록 아바타**는 그 세션 도트 인물 머리 그림이다 (`characterArt.ts` 의 `headImageUrl`, 44px 를 22px 칩에. 조합마다 data URL 하나, `.avatar.head`). 폰·사무실 숨김에서도 목록 때문에 아틀라스를 읽는다. 읽기 전·못 읽음·마스크에 없는 인물이면 빈 `--avatar-bg` 칩. `web/src/dotCharacter.ts` 는 세션 ID 해시(`hashOf`, FNV-1a)로 도트 인물 프리셋을 고른다 (순수, `dotCharacter.test.ts`). `web/src/CharacterPicker.tsx` 는 ✎ 이름 모달의 인물 고르기: "Auto"(해시로 고른 리더 풀 인물) + 아틀라스 인물 전부를 정면 `office-v5-down` 아틀라스 PNG(255색 팔레트)를 배경으로 잘라(idle 첫 칸 위쪽 80px) 보인다. 인물을 고르면(자동이 아니면) 아래에 큰 미리보기(idle 첫 칸 위쪽 96px 를 색을 바꿔 2배)와 머리(기본색 + 8색 `HAIR_COLORS`)·윗옷(기본색 + 10색 `TOP_COLORS`) 색 칸이 나온다. 기본색 칸은 점선 테두리이고 값은 null. 인물을 바꾸면 색은 기본색으로 돌아간다. 저장하면 모달이 `PATCH` 이름 다음에 인물·색 중 하나라도 바뀌었을 때만 `PUT /api/sessions/:id/character` 를 부른다 (자동이면 `{ id: null }`). 외부 세션도 색은 같고 **책상 앞면 회색 명패**(자리 카드에는 "External session")로 구분 (캐릭터를 회색으로 하면 사무실이 죽어 보여서 바꿈). 목록 머리·인물 고르기는 정면 아틀라스와 정면 마스크(`office-v5-down-recolor`)를 쓴다 (`characterArt.ts` 의 `CHARACTER_ATLAS`)
